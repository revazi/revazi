# GitHub Profile Development Phases

## Phase 1 — Repository Audit
Inventory every public repository, including README quality, topics, descriptions, language, maturity, and maintenance status.

Deliverable:
- repo_inventory.md

## Phase 2 — Identity Audit
Identify the common engineering themes represented by the repositories and produce a concise positioning statement.

Deliverable:
- identity.md

## Phase 3 — Repository Classification
Group repositories into Current Projects, Open Source, Experiments, Learning, and Archived.

Deliverable:
- repository_map.md

## Phase 4 — Consistency
Standardize descriptions, topics, licenses, README structure, and branding.

## Phase 5 — Profile README
Generate and maintain the GitHub profile README.

## Phase 6 — Navigation
Recommend pinned repositories, repository ordering, and discoverability improvements.

## Phase 7 — Continuous Maintenance
Re-run audits whenever repositories materially change.
